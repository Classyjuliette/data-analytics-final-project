# Data Analytics Final Project

## Project Overview

This repository contains my final Data Analytics project, demonstrating the use of multiple data analysis tools and techniques.

The project covers four major areas:

- Excel
- MySQL
- Power BI
- Python

## Project Structure

### 01 - Excel
Contains the Excel analysis, including:
- Retail sales analysis
- Data modelling with Power Pivot
- Macros
- Project report
- Data model screenshot

### 02 - SQL
Contains the MySQL project, including:
- SQL queries
- MySQL Workbench project
- Project presentation

### 03 - Power BI
Contains the Power BI analysis, including:
- Data import
- Data cleaning and transformation
- Data modelling
- Relationships
- Visualizations
- Project report

### 04 - Python
Contains the Python data analysis project, including:
- Employee dataset
- Python Jupyter Notebook
- Project report

## Tools Used

- Microsoft Excel
- Power Pivot
- MySQL Workbench
- Power BI
- Python
- Jupyter Notebook
- GitHub

## Objective

The objective of this project is to demonstrate practical data analytics skills, from data preparation and analysis to data modelling, visualization, and reporting.
